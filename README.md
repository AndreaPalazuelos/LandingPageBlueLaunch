# Blue Launch - Landing Page

Sitio web oficial de la entrega final del equipo **Blue Launch** (Tecnológico de Monterrey).

## 🚀 Características
- **Identidad Visual Oficial:** Paleta de colores exactos (#0D183E, #D4AF37, #FFFFFF), iconografía y tipografías tecnológicas (`Orbitron`, `Rajdhani`).
- **Reloj Futurista Conteo Regresivo:** Configurado automáticamente hacia el 30 de noviembre de 2026.
- **Efectos de Audio:** Sonido interactivo de cuenta regresiva sintetizado vía Web Audio API.
- **Animaciones Orbitales:** Cohetes vectoriales flotantes en fondo animado y campo estelar en Canvas.

## 📦 Despliegue en GitHub Pages
1. Descomprime este archivo `.zip`.
2. Sube los archivos (`index.html`, `style.css`, `script.js`) a tu repositorio de GitHub.
3. En GitHub, ve a **Settings** > **Pages**.
4. En **Build and deployment**, selecciona la rama `main` (o `master`) y la carpeta `/root`.
5. Haz clic en **Save**. ¡Tu sitio estará listo en un par de minutos!
